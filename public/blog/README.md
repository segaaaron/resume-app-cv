# Blog cover photos

Drop a cover photo here named **exactly after the post slug** and it becomes that
card's cover on the blog index (framed automatically with the topic gradient tint
+ icon, so every card stays on-brand). No file for a slug → the illustrated
résumé-sheet tile is used instead. Detected at build time.

- Accepted extensions (first match wins): `.webp`, `.jpg`, `.jpeg`, `.png`, `.avif`
- Recommended: landscape, ~800×640+, optimized (WebP or JPG q≈80). The card crops
  with `object-cover`, so keep the subject roughly centered.
- Source: Unsplash (free license) or your own. Full-bleed photo works best; the
  brand tint + bottom scrim handle contrast, so busy photos are fine.
